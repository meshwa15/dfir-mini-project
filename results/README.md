# Results Directory

## Purpose
This directory stores derived analysis outputs, parsed artifacts, tool execution logs, and validation summaries.

## Structure
- `memory/`: Contains command logs and structured text/CSV outputs generated by Volatility 3 plugins (e.g., `windows.info`, `windows.pslist`, `windows.pstree`, `windows.cmdline`, `windows.netscan`, `windows.malfind`).
- `endpoint/`: Contains outputs from endpoint triage parsers (e.g., Prefetch, Amcache, Shimcache, Event Logs) if disk evidence is analyzed.
- `validation/`: Contains validation reports generated by `scripts/validate_results.py`.

## Rules
- Tool outputs must be authentic, reproducible, and derived directly from executed forensic tools.
- Raw evidence dumps must never be placed in this folder.

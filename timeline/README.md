# Incident Timeline Directory

## Purpose
This directory contains chronological correlation records reconstructed from memory and endpoint forensic artifacts.

## Files
- `incident-timeline.csv`: The primary tabular timeline documenting observed forensic events, source artifacts, timestamps (normalized to UTC), confidence ratings, and analyst interpretations.

## Methodology
- Every timeline entry links to a specific evidence artifact and output line.
- Time intervals, clock drifts, and uncertainty boundaries are noted explicitly.
